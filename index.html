ウェブPDF保存ツール

ウェブページを「出典URL・取得日の記録付きPDF」として保存する作業を支援する単一HTMLツールです。URLとファイル名を入力すると、日付タグ付きのファイル名と、ブラウザ（Edge／Chrome）のヘッドレス印刷によるPDF化コマンドを生成します（Windows・Mac対応）。保存先は既定でダウンロードフォルダです。保存後、PDFは各自の管理場所（共有ドライブ等）へ移動してください。

1. 入力

ファイル名に使えない文字（\ / : * ? " < > |）は自動で「_」に置き換わります。

「その他」を選んだ場合: エクスプローラーで目的のフォルダを開き、アドレスバーをクリックしてパスをコピーし（Ctrl+C）、ここに貼り付けてください。Finderで目的のフォルダを選び、option+command+C でパスをコピーして、ここに貼り付けてください。

2. 生成結果

出典URLとファイル名を入力すると、ここに生成結果が表示されます。

日付タグ付きファイル名
ワンクリックPDF作成

ダウンロードした .bat ファイルをダブルクリックすると、Edgeがバックグラウンドでページを取得し、保存先フォルダにPDFが作成されます。完了・失敗のメッセージが黒い画面に表示されます。
※ ブラウザやWindowsが「この種類のファイルは危険…」と警告した場合は「保存」「実行」を選んでください（このページがその場で生成したファイルで、中身は下のEdgeコマンドと同じです）。

コマンドを自分で実行する場合（Edge PDF化コマンド）

コマンドプロンプト（cmd）に貼り付けて実行します（%USERPROFILE% はcmdが自動で展開します）。ヘッドレス実行のため画面は表示されません。生成後、PDFを開いて内容を確認してください。

ターミナル用コマンド

「ターミナル」（Launchpad →「その他」、またはSpotlightで「ターミナル」と検索）を開き、このコマンドを貼り付けて return を押すと、保存先フォルダにPDFが作成されます。ブラウザは上の「お使いのパソコン」欄で Chrome／Edge を選べます（インストールされているものを選択）。

3. 使い方（作業の流れ）

  1. 「1. 入力」に、保存したいウェブページのURLと、付けたいファイル名を入力する（ファイル名には ファイル名_YYYYMMDD.pdf の形で取得日のタグが自動で付きます）。
  2. 「2. 生成結果」に表示される「PDF作成バッチ（.bat）をダウンロード」を押し、ダウンロードされた .bat をダブルクリックする。「2. 生成結果」に表示されるターミナル用コマンドをコピーし、「ターミナル」に貼り付けて return を押す。保存先フォルダ（既定はダウンロードフォルダ）にPDFが生成される。
  3. 生成されたPDFを開き、内容が正しく出力されているか確認する。
  4. 確認したPDFを、各自の管理場所（共有ドライブの該当フォルダ等）へ移動し、必要に応じて文書台帳にURL・取得日を記録する。

コマンドでうまく保存できないページ（ログインが必要・レイアウトが崩れる等）

ヘッドレス印刷はログイン後のページを取得できず、JavaScript主体のページではレイアウトが崩れることがあります。その場合は、保存したいページをブラウザで開いて Ctrl+Pcommand+P を押し、送信先「PDFに保存」を選んでください。詳細設定（「設定をさらに表示」）の「ヘッダーとフッター」をオンにすると余白にURLと日付が印字され、同じく出典の記録になります。ファイル名は「2. 生成結果」の日付タグ付きファイル名を付けて保存してください。

※ 「コマンドが見つからない」「No such file or directory」と出る場合は、ブラウザのインストール先が標準と異なります。コマンド内のパスを C:\Program Files\Microsoft\Edge\Application\msedge.exe に読み替えて実行してください。「お使いのパソコン」欄で Chrome／Edge を切り替えるか、コマンド内のアプリのパスを実際のインストール先に読み替えてください。
※ 旧いバージョンでレイアウトが崩れる場合は --headless を --headless=new に変えて試してください。
