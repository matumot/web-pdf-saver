# web-pdf-saver — ウェブPDF保存ツール

ウェブページを「出典URL・取得日の記録付きPDF」として保存する作業を支援する、**単一HTMLファイル**のツールです。
インストール・外部ライブラリ・サーバーは不要で、ブラウザで開くだけで動作します。

ウェブ上の公開情報（規定・募集要項・技術資料など）を「いつ・どこから取得したか」を記録しながらPDFで収集・保管する用途を想定しています。

**▶ すぐ使う（インストール不要）: https://matumot.github.io/web-pdf-saver/**

リポジトリ: https://github.com/matumot/web-pdf-saver

## 機能

- **日付タグ付きファイル名の生成** — 入力したファイル名に取得日を付けた `ファイル名_YYYYMMDD.pdf` を生成。ファイル名に使えない文字（`\ / : * ? " < > |`）は入力時に自動で `_` に置換
- **かんたんPDF作成（Windows / Mac / Linux対応）** — ブラウザのヘッドレス印刷機能（`--headless --print-to-pdf`）を使ったPDF化コマンドを生成。
  - **Windows**: バッチファイル（.bat）をダウンロードしてダブルクリックするだけ（Edgeを使用）
  - **Mac**: 表示されたコマンドをコピーして「ターミナル」に貼り付けて実行（Chrome／Edgeを選択可）
  - **Linux**: 同じくターミナルで実行（Chrome／Chromium／Edgeを選択可）
- **保存先の選択** — ダウンロード／デスクトップ／ドキュメントのプリセット、または任意のパスを指定可能
- **出典の自動記録** — ヘッドレス印刷はページの余白（ヘッダー・フッター）にURLと日付を印字するため、生成されたPDF自体が出典の記録になる

## 動作環境

- Windows 10 / 11 ＋ Microsoft Edge（標準のインストール先 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe` を想定。異なる場合は生成されたコマンド内のパスを読み替えてください）
- または macOS ＋ Google Chrome もしくは Microsoft Edge（`/Applications` 配下の標準インストールを想定）
- または Linux ＋ Google Chrome／Chromium／Microsoft Edge（`google-chrome`・`chromium`・`microsoft-edge` がPATHにある前提。Chromiumはディストリビューションにより `chromium-browser` の場合あり）
- **Safari・Firefox だけの環境ではコマンド方式は使えません**（ヘッドレス印刷機能がないため）。Chrome／Edge をインストールするか、後述の印刷メニュー（`command+P` / `Ctrl+P`）からの保存を使ってください
- ツール自体の表示には Edge / Chrome / Safari 等のモダンブラウザが使えます（OSは自動判定・手動切替可）

## 使い方

1. `index.html` をブラウザで開く（ダウンロードしてダブルクリックでも、GitHub Pages のURLでも可）
2. 保存したいウェブページの **URL** と **ファイル名** を入力する（取得日は今日が初期値）
3. 必要なら保存先フォルダを選ぶ（既定はダウンロードフォルダ）
4. **Windows**: 「PDF作成バッチ（.bat）をダウンロード」を押し、ダウンロードされた .bat をダブルクリックする。**Mac / Linux**: 表示されたターミナル用コマンドをコピーし、ターミナルに貼り付けて実行する
5. 保存先フォルダに日付タグ付きのPDFが作成されるので、開いて内容を確認する

### ログインが必要なページ・レイアウトが崩れるページ

ヘッドレス印刷はログイン後のページを取得できません。その場合は、対象ページをブラウザで開いて `Ctrl+P` →
送信先「PDFに保存」を選び、詳細設定の **「ヘッダーとフッター」をオン** にして保存してください。
余白にURLと日付が印字され、同様に出典の記録になります。
Mac の Safari では `command+P` →「詳細を表示」→「ヘッダとフッタをプリント」にチェック → 左下「PDF」→「PDFとして保存」、
Firefox では印刷画面の「詳細設定」→「ヘッダーとフッターを印刷」にチェックして PDF に保存します。

## .bat ダウンロード時の警告について

ブラウザや Windows が「この種類のファイルは危険な可能性があります」と警告することがあります。
この .bat はツールのページがその場で生成したもので、中身は Edge のPDF印刷コマンド1行です
（ページ内の折りたたみ「コマンドを自分で実行する場合」で同じ内容を確認できます）。
気になる場合は .bat をメモ帳で開いて中身を確認してから実行してください。

## 制約事項

- ブラウザのセキュリティ上、HTMLページから直接ローカルのプログラムを起動することはできないため、「バッチをダウンロード → ダブルクリック」（Windows）または「コマンドをコピー → ターミナルで実行」（Mac / Linux）の2段階になっています
- JavaScript の動作が前提のページ（SPA等）は、ヘッドレス印刷ではレイアウトが崩れることがあります（その場合は上記の `Ctrl+P` 方式を使用）
- 対象サイトの利用規約・著作権の範囲内でご利用ください
